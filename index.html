Update SAIDI SAIFI ENS

File "LAPORAN SAIDI SAIFI" per UP3 (.xlsx): satu file per UP3, atau satu workbook berisi banyak sheet UP3 (misalnya ALL_SAIDIFI…xlsx). Semua sheet berformat laporan UP3 dibaca; UP3 dan bulan dibaca dari isi sheet. Untuk workbook berisi banyak bulan, hanya bulan yang belum lengkap di dashboard yang diambil.

Update Event Padam Penyulang

Detail gangguan APKT (.xlsx), satu bulan atau banyak bulan, dengan kolom NO. LAPORAN, KODE, BIDANG, JENIS PADAM, UNIT, BULAN, ULP, PENYULANG dan P/S. Tab Database Penyulang ikut diperbarui dari file yang sama. File besar (ratusan MB) butuh beberapa menit untuk dibaca.

Update Database Penyulang

Database penyulang (.xlsx) seperti Penyulang.xlsx: kolom Nama Unit Parent, Description, Nama Unit, Assetattrid, Alnvaluedesc, Status, Tahunbuat, Latitudey dan Longitudex. Data gangguan per penyulang tetap dari file APKT terakhir.

Update Koreksi Cleansing

Master KC (.xlsx) dengan kolom Jenis Transaksi, Distribusi, Area, Tahun Bulan, Tanggal Approval 2 dan KODE J. Hanya event dengan Tanggal Approval 2 terisi yang dihitung; seluruh data tab Koreksi Cleansing diganti dengan isi file.

Cara memperbarui

  1. Klik Unggah & update langsungPilih kartu tab yang ingin diperbarui. Panel unggah terbuka di bawah kartu.
  2. Pilih file dan periksaCek ringkasan per UP3 atau per bulan. Hapus file atau centang bulan yang tidak ingin diganti.
  3. Klik Update dashboard sekarangData dihitung ulang dan disimpan di dashboard. Ringkasan, grafik, tabel dan peta di tab terkait langsung berganti.
  4. Cek info updateBaris info database di atas tiap tab menunjukkan waktu, periode data dan file sumber yang baru.
