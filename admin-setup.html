Atur admin dashboard

Halaman ini untuk pemilik repo. Di sini Anda mengatur password untuk membuka dashboard, serta akun admin (nama dan password) yang boleh menyimpan unggahan data.

1. Token GitHub

  1. Buka GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → pilih repo dashboard ini.
  3. Permissions → Contents: Read and write. Atur masa berlaku token.

Token hanya dipakai di halaman ini untuk dienkripsi dengan password admin, lalu disimpan ke admin-keys.js di repo. Token aslinya tidak pernah disimpan dalam bentuk terbaca.

2. Password akses dashboard

Belum aktif. Saat diaktifkan, semua file data di repo dienkripsi sehingga dashboard hanya bisa dibuka dengan password ini. Proses ini perlu token di langkah 1 dan memakan waktu sekitar 1 menit.

Aktif. Tambah password baru (mis. untuk kelompok pengguna lain) atau ganti password dengan memakai salah satu password akses yang sekarang.

    Label yang sudah ada akan diganti passwordnya.

    3. Tambah atau ganti password admin

    Minimal 10 karakter. Gunakan password yang tidak dipakai di tempat lain. Nama yang sudah ada akan diganti passwordnya.

    Admin terdaftar

      Menghapus admin juga memerlukan token di langkah 1. Perubahan aktif di dashboard setelah GitHub Pages diperbarui (1–2 menit).
